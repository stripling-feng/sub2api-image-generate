# 视频工作台自动连接设计

## 目标

删除视频工作台工具栏中的“连接”按钮。API Key 已保存时页面打开后自动绑定；用户修改 API Key 时，停止输入 700ms 后自动重新绑定。

## 行为

- 复用图片工作台现有的 700ms 防抖模式，不新增依赖或公共抽象。
- API Key 每次变化都同步写入 `localStorage`。
- 少于 8 个字符时不发送绑定请求，并清除当前会话资料，避免继续使用旧 Key。
- 合法 Key 自动调用现有 `/api/session/bind`，成功后加载视频历史。
- 自动绑定失败时继续显示现有错误信息。
- 页面卸载时清理防抖定时器。

## 范围

只修改 `client/src/VideoWorkbench.vue`，不调整图片工作台、后端接口或认证协议。

## 验证

- 静态检查确认连接按钮不存在，API Key 监听器会触发自动绑定。
- 浏览器验证已有 Key 自动加载余额/历史，修改 Key 后自动重连。
- 运行客户端类型检查和生产构建。
