# 视频工作台白色主题设计

## 目标

将 `/video` 改为独立的白色工作台风格，不影响图片工作台、后台管理或现有视频生成交互。

## 设计

- 在 `VideoWorkbench.vue` 的 `.video-studio` 上覆盖现有 CSS 颜色变量。
- 页面背景使用浅灰白，工具栏、历史抽屉和创作台使用白色。
- 边框使用中性浅灰，正文使用近黑色，次要文字使用中灰色。
- 生成按钮继续使用青绿色作为唯一高强调操作色，错误状态保持红色。
- 视频播放器区域继续使用黑色背景，以保证视频内容显示正确。

## 边界

- 不修改 `styles.css` 的全局明暗主题。
- 不增加主题切换按钮、状态或依赖。
- 不改模板、接口、参数、计费和任务逻辑。

## 验证

- 运行 `npm --prefix client run typecheck` 和 `npm --prefix client run build`。
- 浏览器检查桌面和移动端的文字对比度、边框、输入框、按钮、抽屉及无横向溢出。
- 返回图片工作台确认其主题不受影响。
