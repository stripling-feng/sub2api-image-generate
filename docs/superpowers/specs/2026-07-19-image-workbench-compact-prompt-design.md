# 图片工作台精简设计

## 目标

精简图片工作台的非必要信息，并降低底部提示词输入区的默认高度，让生成结果获得更多可视空间。

## 改动

- 删除左侧“切换到视频工作台”入口，不调整 `/video` 路由或视频工作台本身。
- 删除模型参数区的服务商展示，保留预计扣费金额。
- 将提示词输入框高度从 `190-280px` 调整为 `120-180px`，保留浏览器原生的垂直拖动能力。

## 验证

- 图片工作台不再显示视频工作台入口和服务商名称。
- 预计扣费仍正常显示。
- 桌面和移动视口下提示词输入框更矮，内容不溢出，生成按钮仍可见可用。
- 客户端类型检查和构建通过。
