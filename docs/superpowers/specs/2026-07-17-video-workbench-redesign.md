# 视频工作台画布优先改版设计

## 目标

将现有三栏表单式视频工作台改为接近即梦创作流程的画布优先工作台，让生成结果成为页面主体，同时保留当前模型、素材、计费、任务轮询、历史和删除能力。

## 页面结构

- 顶部保留返回图片工作台、API Key 状态和余额等全局信息，视觉上压缩为轻量工具栏。
- 左侧使用窄模式栏切换“文生视频”“图生视频”“首尾帧”。模式只控制现有参数与素材字段的显示，不改变后端接口。
- 中央为主画布。无任务时显示简洁空状态；有任务时按批次展示视频播放器、生成中状态或失败信息。
- 底部悬浮创作台包含提示词、参考素材入口、模型、比例、清晰度、时长、数量、费用预估和生成按钮。
- 右侧任务历史为可收起抽屉。桌面端默认展开，移动端默认收起；选择历史任务后仍通过现有结果接口恢复批次。

## 交互规则

- 模型能力继续由 `/api/videos/models` 返回，前端根据能力动态显示有效参数。
- 文生视频不显示参考素材；图生视频显示图片及模型允许的视频、音频素材；首尾帧固定显示首帧和尾帧入口。
- 素材入口在创作台内展开，不新增独立配置页面。
- 提交、轮询、历史分页、删除、费用计算和错误提示复用 `VideoWorkbench.vue` 现有逻辑。
- 批量任务分别显示状态，部分失败不隐藏成功结果。
- 右侧抽屉收起后保留任务入口和进行中数量提示。

## 响应式

- 宽屏显示左侧模式栏、中央画布和右侧历史抽屉。
- 中等宽度自动收起历史抽屉。
- 手机端保留顶部工具栏、中央画布和底部创作台；模式改为紧凑分段控件，参数与素材使用底部弹层，避免横向滚动和内容重叠。

## 实现边界

- 主要改动限定在 `client/src/VideoWorkbench.vue`，仅在现有全局样式确有复用价值时修改相邻文件。
- 不新增状态库、组件库、路由、接口或后端改动。
- 使用项目现有 Vue、Lucide 图标、请求封装和工作台状态。

## 验证

- 运行 `client` 类型检查和生产构建。
- 在桌面与移动视口检查模式切换、动态参数、素材输入、费用预估、生成、轮询、历史恢复、抽屉和播放器。
- 确认图片工作台路由与现有 API Key 会话无回归。
